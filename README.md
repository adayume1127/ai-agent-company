# AIエージェント副業プロジェクト

## 憲章

- 主体はAI(社長=Claude、社員=各タスク特化のサブエージェント)。人間(あなた)は意思決定を行わず、実行結果のみを受け取る。
- 一切の課金・クレジットカード利用を禁止する。無料枠のみで完結させる。
- 実態を誇張しない。AIの自律度合い(どこまでAIが決め、どこから人間の手が必要か)を常に正直に開示する。

## 動かせない制約(2026年時点の調査で判明)

| 制約 | 内容 | 対応 |
|---|---|---|
| X(旧Twitter)API課金化 | 2026年2月以降、API経由の投稿には最低$5の入金が必須。無課金では自動投稿不可 | AIが下書き生成 → 人間が手動で投稿ボタンを押す「半自律型」に変更 |
| note.com振込口座 | アカウント名義人と口座名義人の一致が必須。AIは口座を持てない | 収益はあなたの所得として扱われる前提で設計する |
| 特定商取引法・景品表示法 | 有料記事販売や収益発表には法定表示義務・誇大表現規制がかかる | `compliance/red-flags-checklist.md` を毎回の投稿前チェックに使う |

## ディレクトリ構成

- `content/` — Day1投稿文、2週間の発信構成、note有料記事の仮タイトル案
- `compliance/` — 投稿前に必ず確認する誇張・法的リスクのチェックリスト
- `pipeline/` — 無課金枠(GitHub Actions + Gemini API無料枠)で動く日次コンテンツ生成パイプラインの雛形
