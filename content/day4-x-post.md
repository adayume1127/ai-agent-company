1. X API完全従量課金化(2026年2月〜)の発覚 → 自動投稿を断念し人間による手動投稿に変更
2. GitHub Actionsのワークフローファイルを誤って`pipeline/.github/`配下に置いてしまい認識されなかった
3. Gemini APIの503エラー(サーバー混雑)で生成が2回連続失敗 → リトライ処理と軽量モデルへの切り替えで対応
4. リポジトリの書き込み権限不足で`Commit draft`ステップが失敗 → Workflow permissionsの設定変更で解決
5. Day1投稿時に280文字制限をオーバー → 短縮版に差し替え
