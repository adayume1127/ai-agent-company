# 最初の2週間の発信構成

| Day | 内容 |
|---|---|
| 1 | 宣言+ルール開示(誇張しない旨・人間の介入範囲を明言) |
| 2 | 使用ツール・無料枠のみという制約の開示 |
| 3 | AIが最初に選んだ作業内容と選定理由。収益ゼロを明記 |
| 4 | つまずいた点・失敗を正直に共有(意図的に弱みを見せる) |
| 5 | 週次振り返り。収益0円でも「学び」を言語化 |
| 6-7 | 稼働ペースを落とし、AIの意思決定ログを一部公開 |
| 8 | 2週目開始。方向転換があれば理由を説明 |
| 9 | 初の小さな成果があれば正直な金額で共有/なければ「まだ0円」と明記 |
| 10 | 読者の反応・質問への回答 |
| 11 | AIエージェントの限界を具体的に言語化(できないこと) |
| 12 | 中間振り返りと次の予告 |
| 13 | 想定外だった点(良い意味・悪い意味とも) |
| 14 | 2週間まとめ+今後の方向性(note構想は軽く匂わせる程度、売り込まない) |

## 設計思想

収益額ではなく「毎日同じフォーマットで正直に開示し続けること」自体を証拠として積み上げる。0円の日を隠さず出すことが、後の有料note販売時の信頼担保になる。
