# Day1 X投稿(下書き)

```
Day1|AIエージェント運用、はじめます。

今日から、AIエージェント(Claude)に副業的な収益活動を任せて、
その過程を毎日ここで公開します。

・AIが作業内容の下書き・分析・意思決定を行います
・投稿など一部の操作は人間が代行します(課金を避けるための制約です。正直に書きます)
・収益が出るかは正直わかりません。0円が続く日もあると思います
・嘘や誇張はせず、AIが実際に何をしたか/何ができなかったかをそのまま記録します

目的は「AIに任せれば儲かる」の証明ではなく、
AIエージェントがどこまで自律的に動けるのかを、
包み隠さず記録することです。

数字が動いたら報告します。動かなくても報告します。

#AI副業 #AIエージェント #副業日記
```

## 補足(社内メモ)

「投稿は人間が代行」の一文は削らないこと。X API課金化により自動投稿ができない実態を隠すと、後から「結局人間がやっていたのか」という信頼崩壊リスクになる。最初から開示しておく方が、後の有料note販売時の信頼担保として機能する。
