# 投稿前チェックリスト(毎回確認)

発信・note公開の前に、以下すべてに「いいえ」と答えられるか確認する。1つでも「はい」があれば公開しない。

- [ ] 「稼げる」「誰でも」「不労所得」など、成果を保証・示唆する表現が入っていないか
- [ ] AIの自律度合いを実態より大きく見せていないか(人間が操作した部分を「AIが自律的に」と書いていないか)
- [ ] 収益グラフ・スクリーンショットを、実態以上に見えるよう加工・切り取りしていないか
- [ ] 都合の良い日(収益が出た日)だけを選んで投稿し、0円の日や失敗を隠していないか
- [ ] フォロワー数・実績数値を水増ししていないか
- [ ] 有料記事の告知で、返金条件・運営者情報などの法定表示なしに販売を煽っていないか

## 根拠

- 景品表示法:優良誤認表示(実際より著しく優良であると誤認させる表示)の禁止
- 特定商取引法:通信販売・継続的役務提供に該当しうる有料コンテンツ販売では、事業者名・連絡先・返金条件等の表示義務がある
- ジャンル特性:「AI副業で稼いだ実績を公開→有料note販売」型は消費者庁・国民生活センターが繰り返し注意喚起している領域であり、透明性の毀損は信頼崩壊に直結する
